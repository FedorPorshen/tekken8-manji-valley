# Manji Valley — рабочие договорённости

- Пользователь самостоятельно запускает TEKKEN 6 / TEKKEN 8 и проверяет мод в игре. Не запускать игру, не переключать окна на игру и не пытаться проводить игровой тест через управление компьютером.
- Вносить изменения по замечаниям пользователя. Разрешены проверки файлов, сборки, контейнеров, скриптов и рендеры Blender без запуска игры.
- Разделять «код написан», «сборка проверена» и «работа в игре подтверждена пользователем». Не объявлять интерактивный снег готовым по результатам имитационных тестов.
- Если требуемое поведение недоступно или его реализация ещё не доказана, сообщать об этом прямо.
- Публикацию и push GitHub выполняет пользователь. Обновлять только локальную папку репозитория; не отправлять изменения в сеть без нового явного поручения.
